# Skills Roblox du projet

Chargés automatiquement par Claude Code dans toute session ouverte sur ce dépôt.

| Skill | Rôle | Source |
|---|---|---|
| roblox-map | Générer et vérifier des maps (blockout, terrain, accessibilité) | 1nird/Map-and-Model |
| roblox-3d-model | Générer des modèles 3D Roblox (Blender, UV, budget triangles) | 1nird/Map-and-Model |
| roblox-texture-gen | Textures IA appliquées dans Studio | 1nird/Map-and-Model |
| roblox-vfx | Effets visuels (particules, auras) | 1nird/rbx-vfx-and-sfx-skills |
| roblox-sfx | Sons (banque d'effets du Creator Store) | 1nird/rbx-vfx-and-sfx-skills |
| roblox-thumbnail | Miniatures de jeu | 1nird/rbx-thumbnail (non versionné ici, voir .gitignore) |

Les étapes « dans Studio » de ces skills demandent le connecteur Roblox Studio, donc une session sur un ordinateur avec Studio ouvert.
